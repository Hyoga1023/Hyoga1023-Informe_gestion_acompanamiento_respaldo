Sistema de Registro de Mesas de Trabajo — Asistencia Empresarial

Descripción

Herramienta web para la estandarización del registro de las mesas de trabajo entre los ejecutivos de Asistencia Empresarial y los empleadores asignados, con generación automática de Excel histórico y acta en PDF.

Requisitos

  • Navegador web moderno (Chrome, Edge o Firefox).
  • Conexión a internet, únicamente para la carga de librerías externas vía CDN.
  • No requiere instalación, servidor propio ni permisos de administrador.

Uso básico

  • Ingresar al enlace de la aplicación desde el navegador.
  • Diligenciar la información de la mesa de trabajo en el formulario principal.
  • Descargar el Excel histórico (paso obligatorio antes del siguiente).
  • Generar el acta en PDF.
  • Para cargar o actualizar la base de empleadores, usar el módulo "Cargar Base de Datos".
  • Para generar dicha base desde un Excel, usar el conversor "Excel a JSON".

Almacenamiento

Toda la información se guarda localmente en el navegador mediante IndexedDB (a través de la librería localForage); no se transmite a servidores externos ni a la nube.

Soporte

Para dudas, incidencias o solicitudes de mejora, comuníquese con el desarrollador de la herramienta a través del canal de soporte definido por el equipo de Asistencia Empresarial.
