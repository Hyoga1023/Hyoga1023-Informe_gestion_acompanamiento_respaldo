Informe de Acompañamiento Empresas — Asistencia Empresarial

1. Requisitos previos

Para utilizar la herramienta solo se necesita un navegador web moderno (Google Chrome, Microsoft Edge o Mozilla Firefox) y conexión a internet. No se requiere instalación ni permisos de administrador.

2. Registrar una mesa de trabajo

  1. Ingrese la fecha de acompañamiento (se carga automáticamente con la fecha del día).
  2. Digite el NIT del empleador. Si la base de datos ya fue cargada previamente, los campos de Razón Social, Asesor Comercial y los valores de gestión (deudas, rezagos, alerta de ciclo de cobro) se autocompletarán.
  3. Complete la información de asistentes, gestión de deudas, canales digitales, compromisos y agendamiento según lo tratado en la reunión.
  4. El formulario se guarda automáticamente mientras usted trabaja (autoguardado), por lo que no es necesario preocuparse por pérdida de información ante un cierre accidental.
Nota: si necesita retomar un registro guardado automáticamente, use el botón Recuperar al final del formulario.

3. Generar los documentos de la mesa de trabajo

El orden es obligatorio y no se puede alterar:

  1. Primero, descargar el Excel con el botón Descargar Excel. Este paso consolida el registro en el histórico del equipo y habilita el siguiente paso.
  2. Luego, generar el acta en PDF con el botón Generar PDF. Este documento puede firmarse de forma digital o impresa, tanto por el ejecutivo como por el representante del empleador.
Si intenta generar el PDF antes de descargar el Excel, el sistema se lo impedirá y le indicará que primero debe completar la descarga del Excel.

4. Cargar o actualizar la base de datos de empleadores

Desde el menú principal, seleccione Cargar Base de Datos. Allí podrá subir el archivo .json con la información de los empleadores asignados. Una vez cargado, el sistema mostrará la cantidad de empleadores registrados y la fecha de la carga.

5. Convertir un Excel a formato JSON

Si cuenta con la información de empleadores en un archivo Excel, use la opción Convertir Excel a .json del menú. El sistema validará los datos (formato de NIT, valores monetarios, alertas de ciclo de cobro) y le permitirá descargar el archivo .json resultante, listo para cargarlo en el paso anterior.

6. Preguntas frecuentes

¿Qué pasa si borro el formulario por error? Puede usar el botón Limpiar Formulario para reiniciar, o Recuperar para restaurar el último autoguardado.

¿Dónde queda guardada la información? Toda la información se almacena localmente en su equipo (no se envía a internet ni a servidores externos), por lo que es importante conservar los archivos Excel descargados como respaldo.

¿Puedo usar la aplicación desde el celular? No. La herramienta está diseñada exclusivamente para equipos de escritorio o portátil, dado el volumen de información que maneja y por razones de seguridad de la información.
